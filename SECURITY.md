# Security Policy

## Supported versions

The latest `cursor.js` on `master` is the only supported snippet.

## Reporting a vulnerability

This repository ships client-side DevTools snippets. Do not file public issues for anything that could be used to inject into another user's Cursor session or leak secrets from an editor.

Email **s.emad.helmi@gmail.com** with:

- A short description of the issue
- The snippet version (`@version` in the file header)
- Steps to reproduce

You should receive a reply within 7 days.
